## 0.1.5 皮肤切换

用户任务仍是一眼查看上下文、限额余量和重置时间。此次增加外观选择，沿用已确认的一行布局和 32px 高度；默认 Codex 深灰，用可切换皮肤提供其他阅读环境。

| 皮肤 | 表面与强调 | 字体与形状 | 使用理由 |
| --- | --- | --- | --- |
| Codex 深灰（默认） | 中性深灰、浅灰进度 | Segoe UI／微软雅黑 UI，14px 圆角 | 延续用户给出的 Codex 输入框参考 |
| 霜白 | 冷白、深灰读数、蓝灰进度 | 原字体，12px 圆角 | 适合浅色与明亮桌面 |
| 午夜蓝 | 深蓝、淡蓝进度 | 原字体，10px 圆角 | 用冷色与更明确的边界形成差异 |
| 终端 | 低饱和深绿、浅绿进度 | Consolas／微软雅黑 UI，6px 圆角 | 等宽数字、较小圆角，适合终端风格 |

- 调色盘按钮单击轮换四款皮肤，右键菜单直接选择；提示显示当前和下一款名称。
- 选择立即保存到已有配置的 `skin` 字段，保留吸附位置等其他设置。重启后读回；未知皮肤回退 Codex。
- 保存失败时保留当前皮肤与已保存值，提示重试。按钮不获取键盘焦点，也不触发拖动。
- 用实际文字尺寸检测空间；空间不足时收起重置时间或进度条，极窄窗口用“剩余百分比”显示主要限额，限额周期仍在悬停提示中。“旧”和额外限额数量保留。
- 正常、次级、警告和严重警告文字均通过至少 4.5:1 的静态对比度检查。

动效：按钮按下 70ms 缩至 0.94、松开 120ms 恢复；皮肤切换时调色盘轻转 18° 后在 180ms 内归位，深色皮肤之间表面颜色同时过渡，亮暗切换直接到位以避免文字经过低对比度灰色；首次出现 160ms 淡入，隐藏后恢复不重播。遵循 Windows 的客户端动画偏好，关闭时立即到位。未增加持续动画或位置动效。

证据：`skin-preview.html` 与 `images/skins/*.png` 为四款实际 WPF 皮肤对比；`.tmp/native-skins-test/data/layout/` 覆盖四款皮肤、280／360／520／650px 宽度与正常／警告／等待／缓存状态；`.tmp/native-skins-test/data/motion/` 包含三处动效的开始、中间、结束帧。预览使用相同的测试指标。原生按钮与菜单、重启读回、保存失败恢复、拖动隔离和布局边界通过隐藏测试窗口验证，不操作用户鼠标或 Codex 聊天。

## 0.1.6 方案 A：文本与间距

用户选定 A，要求间隔更平均、长度更短。保留默认 Codex 外观、32px 高度、13px 字号及四款皮肤，把最大宽度从 650px 收到双限额 560px／单限额 480px。宽度按实际限额数量和 Codex 窗口宽度选择，不随秒级倒计时或百分比变化伸缩；两处组间留白均分，皮肤按钮另留 8px 操作间距。

- 上下文：`上下文 65% / 256k`，仅显示文字，主行百分比取整数，容量读取当前聊天实际上报的窗口，1k = 1000 Token，最多一位小数。近似值说明、精确比例、完整 Token 数与最近上报时间留在提示中；重名和未匹配分别标记。
- 限额：`限额剩余 5小时87% · 7天24%`，按实际数据最多展示两档，其余保留数量及详情。不补造不存在的周期；未知比例显示 `—`，缓存明确写“缓存”。数值稍加字重、说明与周期用次级色。
- 重置：`5小时重置 2小时18分`，选择最早的未来计划重置，并标明所属周期。只有过期时间时显示“待确认重置”，缺失则“未提供”；其他过期窗口仍在提示里保留待确认状态。完整 `YYYY-MM-DD HH:mm` 北京时间、所有周期倒计时和更新时间放到提示中。
- 倒计时最多两个单位，最细到分钟，不再显示秒。删去主行重复的日历日期和每档重复的“剩余”。同周期的不同桶加名称与序号，保持归属一致。
- 窄窗按实际文字尺寸依次缩短时间单位、合并次要限额数量、收起重置；被收起的时间仍在限额提示中。最窄且有缓存时，“剩余”可缩为“余”，周期小时可写 `h`，上下文文字、比例和缓存标记完整保留。只有超长服务周期或桶名允许省略号。

证据：`images/skins/*.png` 为 560px 四款原生皮肤，`codex-single.png` 和 `frost-single.png` 为 480px 单限额；`skin-preview.html` 显示实际 WPF 预览，`images/skin-comparison.png` 为同屏比较。`.tmp/native-skins-test/data/layout/` 覆盖四款皮肤 × 280／360／480／560px × 正常／警告／等待／缓存，以及单档、未提供、待确认、不到一分钟、未匹配、重名、未知比例、混合重置、同周期多桶等状态。断言检查重置归属、两处留白差≤1px、百分比／缓存不省略、未知值不归零及控件边界。

动效沿用 0.1.5 的首次出现、切换和按钮反馈；此次没有新增动效。主 Agent 看实际原生截图和 100%／200% 比较图自检，未独立评审。皮肤选择、保存失败恢复、拖动隔离与顶部吸附继续通过隐藏原生窗口验证。

## 0.1.8 精简模式

用户提供“图标＋名称”小胶囊截图，要求增加可切换精简模式。沿用浅色／深色与 14px 圆角，精简为 140×28px、13px 字号，只显示一个 18px 圆形状态图标和 `Codex Status`。图标使用插件已有的脉冲线语义，不采用参考截图的产品标识；文字与图标跟随所选皮肤。精简视图不再显示进度、百分比、时间或换肤按钮。

- 右键菜单“精简模式”是双向切换入口，勾选缩小、取消展开；简洁外观不增加额外按钮。

- 悬停胶囊列出当前上下文、账号限额、重置时间与状态，附右键展开提示。后台查询继续运行，数据语义与完整模式相同。

## 0.1.9 左侧图标直接切换
